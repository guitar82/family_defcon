# Family DEFCON

**Current release: v1.1.5 HACS Compliant Release**

Fixes target select button display names so dashboards show the configured target names instead of entity/object IDs such as `family_defcon_select_target_child_1`.

This repo uses `zip_release: true` and expects the GitHub release asset:

```text
family_defcon_v1_1_5.zip
```

After install and HA restart, target buttons should display names like `Henry`, `Marc`, `Maggie`, `Mom`, `Dad`, or your configured labels.
