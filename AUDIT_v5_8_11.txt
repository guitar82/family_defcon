Family DEFCON v5.8.11 pre-release audit notes

Issues found and fixed:
1. Dynamic target button entity IDs were fixed in v5.8.10, but the dashboard styling still parsed friendly names. That could fail if Home Assistant prefixes the friendly name.
   Fix: Dynamic target buttons expose attributes: target, target_slug, is_default_target, is_parent_target. The dynamic dashboard now uses those attributes.

2. Several core dashboard entities relied on Home Assistant name generation.
   Fix: Added suggested_object_id for core text/select/binary/switch/sensor entities so clean installs get predictable entity IDs.

3. Dashboard People sensor pointed to unprefixed person status sensors.
   Fix: Person WiFi status/minutes sensors now use deterministic family_defcon-prefixed IDs, and Dashboard People points to those IDs.

4. Selecting a target from select.family_defcon_dashboard_target only updated the select entity.
   Fix: Added dispatcher update so related dashboard cards refresh.

Known upgrade note:
Existing entity registry entries from older test builds can keep old entity IDs. On a test system, remove old Family DEFCON entities or remove/re-add the integration after installing this build.
